## Two cases

- **Nominativ**: the subject, the one *doing* the action.
- **Akkusativ**: the direct object, the one the action happens *to*.

<Example de="Der Mann sieht den Hund." en="The man sees the dog." note="der Mann = Nominativ (subject), den Hund = Akkusativ (object)" />

## What changes?

Only the **masculine** changes between Nominativ and Akkusativ. Feminine, neuter and plural stay the same.

| Gender    | Nominativ | Akkusativ |
| --------- | --------- | --------- |
| masculine | der / ein | **den** / **einen** |
| feminine  | die / eine | die / eine |
| neuter    | das / ein  | das / ein |

The same goes for possessives: mein → **meinen** (masculine only).

<Example de="Ich habe einen Hund." en="I have a dog." />
<Example de="Ich habe eine Katze." en="I have a cat." />
<Example de="Ich habe ein Buch." en="I have a book." />
<Example de="Ich sehe meinen Mann." en="I see my husband." />
